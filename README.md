# NEXUS

NEXUS is a premium AI Developer Command Center for Adnan Ahmed Bhameshan. The current application includes the dashboard shell, project intelligence, NEXUS AI, experience, skills, GitHub, certifications, and technical journey modules.

## Phase 1 Scope

- React, TypeScript, Vite, Tailwind CSS
- Framer Motion, React Router, Zustand, TanStack Query
- NEXUS light-default design system with dark mode and theme tokens
- Boot sequence with skip preference
- Dashboard shell with sidebar, topbar, mobile navigation
- Connected portfolio modules, resume variants, NEXUS project intelligence, and AWS/Terraform cloud infrastructure project data
- Backend/API/database architecture documentation and FastAPI skeleton

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

The frontend dev server runs on `http://localhost:5173`.
