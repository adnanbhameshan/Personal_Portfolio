# Work Style

## Approach

Adnan is a growth-oriented engineer who learns through implementation. He values practical problem solving, clear system boundaries, documentation, and feedback.

## Working Principles

- Validate technical claims against implementation evidence.
- Prefer maintainable solutions over unnecessary complexity.
- Treat documentation as part of engineering quality.
- Build complete workflows that account for users, data, security, and operations.

## Collaboration

He values collaborative environments that support knowledge sharing, direct communication, and continuous improvement.
