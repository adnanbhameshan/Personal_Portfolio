## Stack

- Cloud: AWS
- Infrastructure as code: Terraform
- Operating environment: Linux and Ubuntu
- Networking: VPC, public/private subnets, route tables, security groups, and controlled application-to-database connectivity
- Compute and access: EC2 and Application Load Balancer
- Database: RDS PostgreSQL
- Storage and permissions: S3 and IAM
- Monitoring: CloudWatch metrics, logs, and alarms
- Delivery: Docker, GitHub Actions, CI/CD

## Engineering Purpose

The project provisions a multi-tier AWS environment using Terraform. It is designed to show repeatable cloud provisioning, network boundaries, secure service connectivity, production-style monitoring, and automated delivery workflows.

## Key Responsibilities Demonstrated

- Provisioning VPC networking with public/private subnets and route tables
- Configuring EC2, Application Load Balancer, RDS PostgreSQL, S3, IAM, and security groups
- Setting up CloudWatch metrics, logs, and alarms for monitoring and troubleshooting
- Containerizing services with Docker
- Supporting GitHub Actions workflows for automated testing, image builds, and deployment
- Using Terraform modules and remote state according to resume source material
