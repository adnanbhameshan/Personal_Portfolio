# VJIT Sports Scheduler

## Summary

VJIT Sports Scheduler is an academic full-stack capstone that replaces spreadsheet, physical-record, and notice-board coordination with a role-based sports-session platform.

## Verified Stack

Node.js, Express.js, PostgreSQL, Sequelize, EJS, Tailwind CSS, Passport.js, bcrypt, connect-flash, CSRF protection, Body-Parser, and CORS.

## Architecture

EJS and Tailwind render role-aware admin and student views. Express manages business logic, Passport.js authentication, CSRF protection, and role checks. PostgreSQL and Sequelize manage users, sessions, and reporting data.

## Engineering Focus

- Role-based access for administrators and students
- Session, resource, and participation workflows
- Secure server-rendered forms and sessions
- Date-range reporting and sports-popularity views

## Status

The project was built and tested in a controlled academic environment. It is not currently presented as a public production deployment. The GitHub repository URL is not yet verified.
